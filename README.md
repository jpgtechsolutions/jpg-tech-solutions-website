# JPG Tech Solutions

Professional software development consultancy serving growing businesses.

## Overview

This repository contains the source code for the JPG Tech Solutions company website, built with Next.js 14 and Tailwind CSS.

## Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel
- **Form Handling:** Formspree

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run production build locally
npm run start
```
