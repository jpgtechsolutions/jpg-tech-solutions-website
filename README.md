# JPG Tech Solutions

Professional software development consultancy serving growing businesses.

## Overview

This repository contains the source code for the JPG Tech Solutions company website, built with Next.js 14 and Tailwind CSS.

## Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel
- **Form Handling:** Formspree

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run production build locally
npm run start
```

## Google Analytics Setup

Create a `.env.local` file in your project root with the following content:

```
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-C4L9Q51107
```

This is required for Google Analytics integration. Do not commit `.env.local` to version control.
